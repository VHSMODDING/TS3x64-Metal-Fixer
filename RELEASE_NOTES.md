## TS3 Mac Fixer 1.2.0

- New: **Recommended graphics settings for Apple Silicon** (optional). Sharper shadows (4096 shadow maps), more detailed textures and Sims, higher nearby detail. Set Sim quality to Very High in the game options.
- New: **Recommended performance settings for Apple Silicon** (optional). Gives the simulation, background jobs, resource loading and texture compositing more processing time per frame (`Sims3.ini` `[Timeslices]`) and raises the resource memory from 20 MB to 512 MB.
- The original `GraphicsRules.sgr` and `Sims3.ini` are backed up and restored by Revert all.
- Includes the snowy-road wall fix and the frosted window flicker fix.
- The app now shows its real version number.

Download the DMG, drag the app to Applications, and right-click Open on first launch. The app is ad-hoc signed and is not notarized. If using Tiny UI Fix, install the ocean and insect fix before regenerating Tiny UI Fix.
