## TS3 Mac Fixer 1.2.0

- New: **Recommended graphics settings for Apple Silicon** (optional). Sharper shadows (4096 shadow maps), more detailed textures and Sims, higher nearby detail. Set Sim quality to Very High in the game options. The original `GraphicsRules.sgr` is backed up and restored by Revert all.
- Fixes walls that show the snowy road behind them in winter.
- Fixes flickering frosted windows on community buildings in winter.
- The native library is now built from the sources in `dylib/` by `scripts/build.sh`.
- The app now shows its real version number.

Download the DMG, drag the app to Applications, and right-click Open on first launch. The app is ad-hoc signed and is not notarized. If using Tiny UI Fix, install the ocean and insect fix before regenerating Tiny UI Fix.
