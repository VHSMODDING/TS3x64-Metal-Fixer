## TS3 Mac Fixer

- Detects installations inside Applications subfolders, including EA Games, and indexed installations elsewhere using Spotlight.
- Displays log messages in English or French to match the app interface.
- Installs the ocean and insect fix in Mods/Overrides and migrates older copies from Mods/Packages. Preserves existing Resource.cfg rules.
- Includes native display, ocean and insect interaction, Smooth Patch, font and shader fixes.
- New: fixes walls that show the snowy road behind them in winter.
- New: fixes flickering frosted windows on community buildings in winter.
- The native library is now built from the sources in `dylib/` by `scripts/build.sh`.

Download the DMG, drag the app to Applications, and right-click Open on first launch. The app is ad-hoc signed and is not notarized. If using Tiny UI Fix, install the ocean and insect fix before regenerating Tiny UI Fix.
